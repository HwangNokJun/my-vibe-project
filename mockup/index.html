파일공유유사 문의 8건 묶음

FAQ 초안
Q. 공유 링크를 클릭하면 접근 권한 오류가 발생합니다.
A. 공유 링크의 만료 기간을 확인해주세요. 링크 생성 시 설정한 유효 기간이 지났거나, 공유 설정이 변경된 경우 이 오류가 발생합니다. 관리자에게 링크 재발급을 요청하시거나, 공유 설정에서 '링크 공유' 옵션이 활성화되어 있는지 확인해주세요.

모바일앱유사 문의 5건 묶음
#1089 ↗▼
FAQ 초안
Q. 모바일 앱에서 파일 업로드가 안 됩니다.
A. 모바일 앱의 저장 공간 접근 권한을 확인해주세요. iOS는 설정 → DirectCloud → 사진/파일 접근 허용, Android는 설정 → 앱 → DirectCloud → 권한에서 확인할 수 있습니다. 권한 설정 후에도 문제가 지속되면 앱을 최신 버전으로 업데이트해주세요.

권한관리유사 문의 4건 묶음
#1103 ↗▼
FAQ 초안
Q. 특정 사용자에게만 폴더 편집 권한을 줄 수 있나요?
A. 네, 가능합니다. 해당 폴더에서 우클릭 → '공유 및 권한 설정'을 선택한 후 사용자를 추가하고 권한을 '편집 가능'으로 설정해주세요. 상위 폴더의 권한이 하위 폴더에 상속될 수 있으니, 상위 폴더 설정도 함께 확인해주세요.

#1131 ↗▼
FAQ 초안
Q. SSO 로그인 후 자동 로그아웃이 발생합니다.
A. 세션 유지 시간 설정을 확인해주세요. 관리자 콘솔 → 보안 설정 → 세션 타임아웃 값이 짧게 설정되어 있을 수 있습니다. 또한 브라우저의 서드파티 쿠키 차단이 활성화된 경우에도 이 문제가 발생할 수 있습니다.

네트워크유사 문의 1건

FAQ 초안
Q. 특정 네트워크(IP)에서만 접속이 안 됩니다.
A. IP 허용 목록 설정을 확인해주세요. 관리자 콘솔 → 네트워크 보안에서 IP 제한 정책 설정 여부를 확인해주세요. 회사 VPN을 사용 중이라면 VPN IP가 허용 목록에 포함되어 있어야 합니다.
