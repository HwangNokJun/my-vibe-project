## 1. 배경 및 문제 정의

브릿지 엔지니어는 매월 Backlog `DIRECTCLOUDINQUIRY` 프로젝트에 쌓인 고객 문의를 수동으로 검토하여 홈페이지 FAQ에 올릴 항목을 선별하고 있다.

**현재 문제:**
- 수작업 소요 시간: 월 30~60분
- 판단 근거 부재: 동일 문의 반복 횟수를 별도 집계하지 않음
- FAQ 작성까지 추가 시간 소요: 후보 선정 후 문구 작성을 별도 진행

## 3. 핵심 기능 (우선순위별)

| ID | 기능명 | 설명 | 우선순위 |
|----|--------|------|---------|
| F-01 | FAQ 적합도 점수 | 각 문의에 AI가 1~5점 FAQ 적합도 점수 부여 | 필수 |
| F-02 | 카테고리 자동 분류 | 문의 내용 기반 카테고리 자동 태깅 | 필수 |
| F-03 | 유사 문의 묶음 보기 | 의미적으로 유사한 문의를 그룹으로 묶어 표시 | 필수 |
| F-04 | FAQ 초안 문구 자동 생성 | FAQ 후보 문의에 대해 Q&A 형태 초안 자동 작성 | 필수 |
| F-05 | Backlog 원본 링크 | 각 문의에서 Backlog 이슈 원본으로 바로 이동 | 필수 |
| F-06 | 기간 필터 | 최근 12개월 기준 분석 대상 기간 설정 | 필수 |
| F-07 | 웹 화면 결과 표시 | 분석 결과를 브라우저에서 테이블 형태로 확인 | 필수 |
| F-08 | Excel 내보내기 | 결과를 Excel 파일로 다운로드 | 향후 확장 |
| F-09 | 자동 스케줄링 | 월 1회 자동 실행 (Cron) | 향후 확장 |
| F-10 | 팀 공유 기능 | 분석 결과를 팀원과 공유 | 향후 확장 |

## 4. 비기능 요구사항

| 항목 | 내용 |
|------|------|
| 대상 사용자 | 브릿지 엔지니어 1인 단독 운영 도구 |
| 실행 주기 | 월 1회 수동 실행 |
| 분석 기간 | 최근 12개월 이내 Backlog 문의 |
| 데이터 소스 | Backlog REST API (DIRECTCLOUDINQUIRY 프로젝트) |
| AI 엔진 | Claude API (claude-sonnet-4) |
| 출력 형태 | 웹 화면 (브라우저 기반 대시보드) |
| 최소 데이터 기준 | 100건 이상 문의 시 클러스터링 정확도 안정적 |

---

## 5. 성공 지표

- FAQ 후보 선정 소요 시간: 30~60분 → **5분 이내**
- 월 1회 안정적 실행 가능
- AI 추천 FAQ 후보 중 실제 등록 비율 **70% 이상**
- 유사 문의 묶음 정확도 **80% 이상** (수작업 검토 기준)

---

## 6. 제약 사항 및 가정

- Backlog API 레이트 리밋: 대량 요청 시 분할 처리 필요
- Claude API 비용: 문의 100건 기준 월 약 $0.5~1 수준
- 클러스터링 정확도: 문의 건수 적을 경우 그룹화 품질 저하 가능
- 프롬프트 튜닝 필요: 초기 카테고리 기준은 실제 데이터로 검증 후 조정

---

## 7. MVP 범위

### ✅ MVP 포함
- Backlog API 연동 (DIRECTCLOUDINQUIRY 프로젝트)
- 최근 12개월 문의 자동 수집
- Claude API 기반 FAQ 적합도 점수 산출 (1~5점)
- 카테고리 자동 분류
- 유사 문의 그룹화 (클러스터링)
- FAQ 초안 Q&A 문구 자동 생성
- 결과 웹 화면 표시 + Backlog 원본 링크

### ❌ MVP 제외 (향후 확장)
- Excel/CSV 내보내기
- 자동 스케줄링 (Cron)
- 팀 공유 기능
- Backlog 자동 태깅
