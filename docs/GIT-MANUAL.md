# 비개발자를 위한 Git 매뉴얼
## Claude Code 프롬프트 중심 가이드

---

## Git이란?

파일의 변경 이력을 저장하는 도구입니다.  
쉽게 말하면 **"문서의 버전 관리"** 예요.

```
Word 문서의 "변경 내용 추적" 기능과 비슷하지만,
훨씬 강력하고 여러 사람이 함께 쓸 수 있어요.
```

| Git 용어 | 쉬운 설명 |
|----------|-----------|
| 레포지토리 (repo) | 프로젝트 폴더 전체 |
| 커밋 (commit) | 변경 내용을 저장하는 것 (=세이브 포인트) |
| 푸시 (push) | 로컬 저장 내용을 GitHub에 올리는 것 |
| 풀 (pull) | GitHub의 최신 내용을 내 컴퓨터로 가져오는 것 |
| 브랜치 (branch) | 원본을 건드리지 않고 작업하는 별도 공간 |
| 머지 (merge) | 브랜치 작업을 원본에 합치는 것 |

## Claude Code에서 Git 작업하기

> **Claude Code를 열고 아래 프롬프트를 그대로 붙여넣으면 됩니다.**

---

### 현재 상태 확인

```
지금 변경된 파일이 있는지 확인해줘.
어떤 파일이 새로 추가됐거나 수정됐는지 보여줘.
```

---

### 파일 커밋하기

```
변경된 파일들을 커밋해줘.
커밋 메시지는 "[작업 내용]"으로 해줘.
```

**커밋 메시지 잘 쓰는 팁:**
```
✅ 좋은 예시
- "docs: add PRD.md (제품 요구사항 문서 추가)"
- "feat: add mockup/index.html (FAQ 분석 화면 목업)"
- "fix: 카드 클릭 시 펼치기 오류 수정"

❌ 나쁜 예시
- "수정"
- "업데이트"
- "asdf"
```

---

### GitHub에 올리기 (푸시)

```
커밋한 내용을 GitHub에 올려줘. (푸시해줘)
```

---

### 커밋 + 푸시 한 번에

```
변경된 파일을 "[커밋 메시지]"로 커밋하고 GitHub에 푸시해줘.
```

---

### 여러 파일을 단계별로 커밋하기

```
파일을 아래 순서대로 나눠서 커밋하고 마지막에 한 번에 푸시해줘.

1. ideation.md → "docs: add ideation.md (1단계 산출물)"
2. docs/PRD.md → "docs: add PRD.md (2단계 산출물)"
3. mockup/index.html → "feat: add mockup (3단계 산출물)"
```

---

### 커밋 이력 확인하기

```
지금까지 커밋한 내역을 보여줘.
최근 10개만 보여줘.
```

---

### GitHub에서 최신 내용 가져오기

```
GitHub에 올라온 최신 내용을 내 컴퓨터로 가져와줘. (풀해줘)
```

---

### 브랜치 만들기

```
"feature/[작업이름]" 이름으로 새 브랜치를 만들고 거기로 이동해줘.
```

**브랜치가 필요한 경우:**
- 실험적인 기능을 테스트할 때
- 원본 코드를 건드리지 않고 수정하고 싶을 때
- 여러 작업을 동시에 진행할 때

---

### 브랜치 작업을 메인에 합치기

```
현재 브랜치 작업을 main 브랜치에 합쳐줘. (머지해줘)
```

## 자주 발생하는 문제와 해결 프롬프트

### 문제 1: 푸시가 안 돼요

```
푸시가 안 되는데 어떤 문제인지 확인하고 해결해줘.
GitHub 로그인 상태도 확인해줘.
```

### 문제 2: 실수로 잘못된 내용을 커밋했어요

```
방금 한 커밋을 취소하고 싶어.
파일 내용은 그대로 두고 커밋만 취소해줘.
```

### 문제 3: 파일을 실수로 삭제했어요

```
[파일명] 파일을 실수로 삭제했어.
마지막 커밋 시점으로 되돌려줘.
```

### 문제 4: GitHub와 내 컴퓨터 내용이 달라요

```
GitHub와 내 컴퓨터 내용이 다른 것 같아.
어떤 차이가 있는지 확인하고 어떻게 해야 할지 알려줘.
```

### 문제 5: 어떤 파일을 커밋했는지 모르겠어요

```
마지막 커밋에 어떤 파일들이 포함됐는지 보여줘.
```

## GitHub CLI (gh) 자주 쓰는 프롬프트

### 이슈 목록 확인

```
GitHub 이슈 목록을 보여줘.
열려있는 이슈만 보여줘.
```

### 이슈 등록

```
GitHub 이슈를 등록해줘.
제목: [이슈 제목]
내용: [이슈 내용]
라벨: MVP
```

### 이슈 닫기

```
이슈 #[번호]를 완료 처리로 닫아줘.
```

### 브라우저에서 GitHub 열기

```
GitHub 레포지토리를 브라우저에서 열어줘.
```

## 매일 쓰는 Git 루틴 (바이브 코딩 버전)

```
작업 시작할 때:
→ "GitHub에서 최신 내용 가져와줘"

작업 중간중간:
→ "지금까지 변경된 파일 확인해줘"

작업 마칠 때:
→ "오늘 작업한 내용을 의미 있는 메시지로 커밋하고 푸시해줘"
```
